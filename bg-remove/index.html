1. 画像

ドラッグ＆ドロップ、貼り付け（Ctrl / ⌘ + V）でも読み込めます。画像はこのブラウザの中だけで処理され、どこにも送信されません。

2. 抜き方

初回だけ実行ライブラリとモデルをダウンロードします（2回目からはブラウザに保存されたものを使います）。WebGPU に対応したブラウザ（Chrome / Edge 推奨）だと速く処理できます。

画像の上をクリックすると、その色を抜く色に追加します（最初は画像のふちで一番多い色を自動で選びます）。色の丸をクリックすると外せます。

4. 保存

保存した PNG は、JIZURA で書き出した動画や透過PNGと動画編集ソフトで重ねて使えます（「中央を空ける（キャラクター用）」と組み合わせると便利です）。

AIモデル：BiRefNet（MIT License）・MODNet（Apache License 2.0）、実行ライブラリ：Transformers.js（Apache License 2.0）。いずれも使うときだけ外部（jsDelivr / Hugging Face）から読み込みます。
